# Xbox import

Preserve the original Xbox image in the material library. A rebuilt XISO is a derived artifact, not a replacement for the source. If the selected Xbox emulator requires a rebuilt image, create a sibling conversion directory and keep the original and converted files together with a manifest containing source and output hashes.

Do not convert Xbox 360 content merely because a converter is available. Use the emulator's required format and encryption/decryption state as the decision point. Never describe a copied ISO as validated until the emulator opens it.
